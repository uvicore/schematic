# 2026-07-29

## Logger config: dated log files + channels for framework 0.4.10

- **Intent:** Update the app scaffold for the framework 0.4.10 logging work so newly generated apps
  get the safe file-logging default and can discover log channels without reading the docs first.
- **Changed — `acme/appstub/config/logger.py`:**
  - `file.file` now defaults to a **date-stamped** path,
    `/tmp/%Y-%m-%d_acme.appstub_{channel}.log`, instead of the static `/tmp/acme.appstub.log`. New
    apps therefore start on the mode that is safe for long-running processes and for multiple
    processes sharing one log (`uvicorn --workers N`), since nothing is ever renamed. The comment
    explains that dropping the `%` tokens reverts to the legacy rename-based rotation.
  - Added `file.retention` (days, `0` = keep forever) with a note that it replaces `backup_count`
    for dated filenames and that `logrotate` is the right tool for compression/size caps.
  - Grouped the legacy `when`/`interval`/`backup_count` keys under a comment saying they apply
    **only** when the path has no strftime tokens — previously it wasn't obvious they were rotation
    specific.
  - Added a commented-out **`channels`** block showing `uvicore.log.channel('Processor')`, the
    inherit-by-default behavior (`{}` is usually enough), a per-channel override example, and the
    rule that channel names cannot contain a dot. Left commented so a fresh app has no channels it
    didn't ask for, but the feature is discoverable right where it's configured.
  - Dropped the unused `from uvicore.typing import OrderedDict` import.
- **Changed — `.env-example`:** the Logging block only listed `LOG_CONSOLE_LEVEL`,
  `LOG_FILE_LEVEL` and `LOG_FILE_PATH`. Added `LOG_FILE_RETENTION` plus the vars the config has
  always read but the example never surfaced: `LOG_CONSOLE_ENABLED`, `LOG_CONSOLE_COLORS`,
  `LOG_FILE_ENABLED`, and the `LOG_ROTATE_WHEN`/`LOG_ROTATE_INTERVAL`/`LOG_ROTATE_BACKUP_COUNT`
  trio. `LOG_FILE_PATH` updated to the dated form to match the config default.
- **Files:** `acme/appstub/config/logger.py`, `.env-example`.
- **Related:** framework `adr/0008-dated-log-files-and-log-channels.md`,
  `framework/journal/2026-07-29.md`, and the new `docs/docs/deeper/logging.md`.
